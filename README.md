  ### 130 Years of USA Names (1880–2010)

  # 👶 130 Years of US Baby Name Trends (1880–2010)

  An interactive demographic exploration platform built with **Python**, **Pandas**, and **Streamlit** to analyze over a century of historical naming patterns from official US Social Security Administration (SSA) birth records.

## 📌 Overview

This project uncovers long-term demographic, cultural, and linguistic shifts across American history through big-data wrangling. By processing and merging annual Social Security birth registers from 1880 through 2010, the dashboard illustrates how baby names rise, peak, and fade over decades, and provides dual-gender popularity tracking for any queried name.

---

## ✨ Key Features

- **Longitudinal Birth Rate Trends**: Multi-line visualization illustrating aggregate annual male and female recorded births over a 130-year span.
- **Most Popular Name per Year**: Chronological stacked analysis charting the single most dominant names for every year (from *Mary* and *John* to *Linda*, *Michael*, and *Jacob*).
- **Gender Birth Ratio Dynamics**: A comparative divergence graph highlighting proportional gender frequency variances across historical eras.
- **Interactive Name Search Engine**: Instant lookup tool allowing users to enter any name (e.g., *John*, *Sara*) and visualize side-by-side time series plots comparing:
  - **Male Trend**: Total births per year assigned to males.
  - **Female Trend**: Total births per year assigned to females.

---

## 🛠️ Tech Stack

- **Language**: Python 3.10+
- **Data Wrangling & Aggregation**: [Pandas](https://pandas.pydata.org/), NumPy
- **Dashboard Framework**: [Streamlit](https://streamlit.io/)
- **Data Source**: US Social Security Administration (SSA) National Data on Given Names
